# 上服务器前联调清单（Ubuntu 22.04，镜像部署）

## 一、本地自检

- [x] 镜像构建：`docker build -t paladmin:local .`
- [x] 单元测试：`go test ./...`（5 个反作弊检测用例通过）
- [x] 启动冒烟：`/health`、登录、PalDefender 状态、回档端点正常
- [x] Python 解析器字段扩展（instance_id / 天赋 / 灵魂 / platform_id）

## 二、推送镜像到 GHCR

```bash
export GITHUB_TOKEN=你的GitHubToken   # 需 write:packages
bash scripts/docker-push.sh latest
# 镜像：ghcr.io/qyc-qyc/palworld-tool:latest
```

## 三、游戏服准备

游戏服 `PalWorldSettings.ini`：
```ini
RESTAPIEnabled=True
RESTAPIPort=8212
RCONEnabled=True
RCONPort=25575
AdminPassword=<强密码>
```

## 四、compose 配置核对

| 项 | 期望值 | 验证 |
|---|---|---|
| `WEB_PASSWORD` | 强密码 | 浏览器登录面板 |
| `REST__ADDRESS/PASSWORD` | `http://palworld:8212` + AdminPassword | 面板仪表盘显示在线人数 |
| `RCON__ADDRESS/PASSWORD` | `palworld:25575` + AdminPassword | RCON 页执行 `ShowPlayers` |
| `SAVE__PATH` | 容器内 Saved 路径 | 玩家页 2 分钟内出现存档数据 |
| 存档卷挂载 | 读写（无 `:ro`） | 回档功能正常 |
| `PROCESS__CONTAINER` | 游戏容器名（如 `palworld`） | 回档可停/启游戏容器 |
| `ANTICHEAT__MODE` | `external`（默认）/ `integrated` | 告警页可见 |

## 五、端到端联调步骤

1. **启动**：
   ```bash
   docker compose up -d
   docker compose logs -f paladmin
   ```
2. **在线同步**：仪表盘应显示在线人数/FPS（60s 内）
3. **存档同步**：等待 2 分钟，玩家页出现存档数据（镜像内已含 sav_cli）
4. **反作弊触发验证**（安全环境）：
   - 用存档编辑器把某测试帕鲁 HP 改到 99999
   - 等待下次存档扫描，告警页出现 S001
   - 首次建议在系统设置关闭 kick/ban，只留 warn
5. **封禁链路**：玩家详情页点踢出/封禁，检查游戏内效果
6. **回档链路**：
   - 先手动备份
   - 配置好 `PROCESS__CONTAINER` 后点"回档"
   - 观察日志：停游戏容器 → 安全备份 → 解压恢复 → 启容器
7. **PalDefender 集成**（可选）：
   - 面板「PalDefender」页显示绿色已连接
   - 游戏内执行 `/imcheater`，告警页出现记录

## 六、常见问题

| 现象 | 排查 |
|---|---|
| 面板打不开 | `docker compose ps`；端口/防火墙 8190 |
| 在线人数为空 | REST 地址/密码错；游戏服与面板是否同网络 |
| 存档不更新 | 存档卷路径错；`docker compose exec paladmin ls /game/Saved` |
| 封禁无效 | UserId 需 `steam_` 前缀；检查 RCON/REST 连通 |
| 回档不停服 | `PROCESS__MODE=docker` 且容器名正确；docker socket 已挂载 |
| 拉取镜像失败 | `docker login ghcr.io`；镜像设为 public |
| 反作弊误报 | 调大阈值/管理员加白名单/用标记误报并解封 |
