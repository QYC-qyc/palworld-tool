# PalAdmin 开发约定

新窗口开始工作前先读此文件，了解代码在哪、规则是什么。

## 技术栈
Go 1.22 + Gin + bbolt | Vue 3 + TypeScript + Naive UI + Vite + Leaflet
运行环境：Linux（Ubuntu 22.04/Debian 12），systemd

## 代码位置

### 后端
- 路由注册：`api/router.go`（静态文件 `/assets`、`/data`、`/icons`、`/map` 必须注册）
- 数据库 bucket：`internal/database/bbolt.go`
- 设置键常量：`service/settings.go`
- 新增可编辑设置：必须在 `api/settings.go` 的 `isEditableKey()` 注册
- 游戏配置 schema（字段定义/范围/分类）：`internal/palconfig/schema.go`
- ini 解析：同文件 `ParseFile()`/`WriteFile()`，读取时去引号、写入时加引号
- 游戏服进程管理：`internal/gamesrv/manager.go`，支持原生 Linux 和 Wine 两种模式
- 面板自更新：`internal/updater/updater.go`
- 轻量反作弊：`internal/detect/detect.go`
- PalDefender 集成：`api/paldefender.go`
- 审计日志：`service/audit/audit.go`，操作类 API 调用 `audit.Add()`
- 定时任务：`internal/task/task.go`
- 在线玩家位置：`internal/tool/rest_api.go` 的 ShowPlayers() 返回 LocationX/Y

### 前端
- 页面：`web/src/views/`，API 封装：`web/src/api/`
- 路由：`web/src/router/index.ts`，菜单：`web/src/views/Layout.vue`
- 字段说明统一用问号图标 + NTooltip（HelpCircleOutline），不在标签后直接写文字
- tooltip 深色背景样式：`:deep(.n-tooltip){background:#1f1f1f!important;color:#fff!important}`
- 耗时操作（安装/更新）用进度弹窗 + 后端轮询接口
- 地图：Leaflet Simple CRS，瓦片在 `web/public/map/tiles/`

## 配置字段规则
- 字段 Min/Max/Step 参考 LootLab：https://lootlab.cn/palworld/settings
- 配置分类（8个页签）：服务器、世界、玩家、帕鲁、战斗、经济与掉落、据点、公会
- 字段 Label 参考官方文档和 LootLab 的中文命名
- 难度预设：选 Easy/Normal/Hard 自动填倍率，改任意倍率自动切回 None
- 新增字段后检查解析时是否需要去引号（字符串类型自动处理，Raw/Multi 类型不加引号）
- Multi 类型输出为 `(A,B,C)` 括号列表

## 地图功能
- 主世界：Leaflet tileLayer 加载 `web/public/map/tiles/{z}/{x}/{y}.webp`（zoom 0-4，149张瓦片）
- treemap.webp：左上角小地图叠加层（另一个地区）
- 坐标映射：游戏坐标 (-1.4M~+1.4M) 归一化到 [0,256]（Simple CRS zoom=0）
- 地图数据来源：LootLab https://lootlab.cn/palworld/map

## 静态资源
- 图标：`web/public/icons/`（tech 464个、pals 299个、items 864个，均压缩到 64/128px）
- 数据 JSON：`web/public/data/`（tech_list.json、pal_list.json、item_list.json）
- 地图：`web/public/map/`
- 后端必须注册所有静态目录路由，否则资源 404

## 更新机制
- 后端下载 tar.gz 到临时目录，setsid+nohup 执行替换脚本，**不能 os.Exit 自杀**
- 下载镜像：ghfast.top / gh-proxy.com / ghproxy.net / 直连
- 前端轮询 `/api/updater/status` 看下载进度，服务重启后轮询 `/health`

## 构建与发布
- CI 必须用 ubuntu-22.04（glibc 2.35 兼容旧服务器）
- Release 产物：paladmin + web/ + data/ + icons/ + map/ + sav_cli + paladmin.service
- 打 tag vX.Y.Z，推送 Gitee + GitHub，保留最近 5 个 tag
- 清理旧 GitHub release：`scripts/cleanup-releases.sh 5`（需要 GITHUB_TOKEN）
