# PalAdmin 开发约定

## 项目概述
PalAdmin 是幻兽帕鲁 Linux 专用服务器管理面板，使用 Go + Vue 3 + Naive UI 开发。
- 后端：Go 1.22+，Gin 框架，bbolt 数据库
- 前端：Vue 3 + TypeScript + Naive UI + Vite
- 运行环境：Linux（Ubuntu 22.04/Debian 12），systemd 服务管理

## 代码规范

### 后端 (Go)
- API 路由统一在 `api/router.go` 注册
- 数据库 bucket 定义在 `internal/database/bbolt.go`
- 配置键常量定义在 `service/settings.go`
- 可编辑的设置键必须在 `api/settings.go` 的 `isEditableKey()` 中注册
- 游戏配置字段定义在 `internal/palconfig/schema.go`，每个字段含 Key/Label/Type/Default/Description/Group
- 游戏服管理在 `internal/gamesrv/`，支持原生 Linux 和 Wine 两种启动模式
- 反作弊：轻量外部检测在 `internal/detect/`；PalDefender 集成在 `api/paldefender.go`

### 前端 (Vue)
- 页面在 `web/src/views/`
- API 调用在 `web/src/api/`
- 字段说明文字统一使用问号图标 + NTooltip，鼠标悬停显示
- 帮助图标使用 `@vicons/ionicons5` 的 `HelpCircleOutline`，class="help-icon"
- 进度条弹窗用于耗时操作（安装、更新），通过后端轮询接口获取状态
- 所有输入框使用 Naive UI 组件，不用原生 HTML 控件

### UI 约定
- 字段标签旁的说明必须用问号图标 tooltip，不直接写文字
- tooltip 使用 `<n-tooltip trigger="hover">`，trigger 为 `<n-icon :component="HelpCircleOutline" class="help-icon" />`
- 帮助图标样式：`font-size:15px; color:var(--n-text-color-3,#999); cursor:help`
- 长说明用 tooltip，短状态提示用 `<n-text depth="3">`
- 按钮区使用 `<n-space>` 包裹
- 卡片标题简洁，操作按钮在卡片底部

### 难度预设
- 选择 Easy/Normal/Hard 时自动填入官方默认倍率值
- 修改任意倍率字段时自动将难度切回 None（自定义）
- 官方预设值定义在 `GameSettings.vue` 的 `difficultyPresets`

### 更新机制
- 面板更新：后端直接下载 tar.gz 到临时目录，用 setsid+nohup 执行替换脚本
- 下载走 4 个镜像：ghfast.top / gh-proxy.com / ghproxy.net / 直连
- 前端轮询 `/api/updater/status` 获取下载进度，服务重启后轮询 `/health`
- 安装脚本在 `scripts/install.sh`，Gitee 地址：`https://gitee.com/QYC-qyc/palworld-tool/raw/main/scripts/install.sh`

## 目录结构
```
api/           HTTP handler
internal/      内部模块
  config/      配置结构与默认值
  database/    bbolt 数据库
  gamesrv/     游戏服进程管理
  palconfig/   PalWorldSettings.ini 解析
  detect/      轻量外部反作弊
  tool/        REST/RCON/备份等工具
  updater/     面板自更新
  logger/      日志
  task/        定时任务
service/       业务逻辑层
web/src/
  api/         前端 API 封装
  views/       页面组件
scripts/       安装脚本
```

## 标签管理
- 每个版本打 git tag（vX.Y.Z）
- 同时推送到 Gitee 和 GitHub
- 保持最近 5 个 tag，删除旧 tag
- GitHub Actions 在 ubuntu-22.04 上构建（保证 glibc 兼容）
- Release 产物：paladmin + web/ + data/ + sav_cli + paladmin.service

## 抓取网页内容的方式

需要读取官方文档或参考网站时，使用本机 Chrome 无头模式抓取（比 curl 能执行 JS、处理动态内容）：

```bash
CHROME="/c/Program Files/Google/Chrome/Application/chrome.exe"

# 抓取页面 DOM（渲染后）
"$CHROME" --headless=new --disable-gpu --no-sandbox \
  --virtual-time-budget=10000 --dump-dom "URL" 2>/dev/null

# 提取纯文本
"$CHROME" --headless=new --disable-gpu --no-sandbox \
  --virtual-time-budget=10000 --dump-dom "URL" 2>/dev/null \
  | sed 's/<[^>]*>/\n/g' | sed '/^$/d'
```

- 官方配置文档：`https://docs.palworldgame.com/settings-and-operation/configuration/`
- 官方命令文档：`https://docs.palworldgame.com/settings-and-operation/commands/`
- PalDefender 文档：`https://ultimeit.github.io/PalDefender/`

## 常见问题
- sav_cli 在旧系统报 GLIBC 错误：CI 必须用 ubuntu-22.04
- REST/RCON 连不上：检查 AdminPassword、端口、Base64 设置
- 备份不执行：检查游戏服是否运行（未运行时跳过备份）
- 面板更新卡住：确保后端不自杀，用 setsid 独立执行替换脚本
