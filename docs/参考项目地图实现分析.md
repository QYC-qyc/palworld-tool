
使用的组件：
- `LMap` — 地图容器
- `LTileLayer` — 瓦片底图
- `LMarker` + `LIcon` — 标记点
- `LPopup` — 点击弹出卡片
- `LTooltip` — 常驻标签（玩家昵称、据点聚合数量）
- `LCircle` — 据点范围圆圈

### 2.2 坐标系统 / CRS 配置

使用 Leaflet 的 **`Simple` CRS**（笛卡尔平面坐标系），而非地理投影：

```html
<l-map
  ref="mapRef"
  style="width: 100%; height: 100%"
  crs="Simple"
  v-model:zoom="zoom"
  :use-global-leaflet="false"
  :center="[-128, 128]"
  :min-zoom="0"
  :max-zoom="6"
  :options="{ zoomControl: false, attributionControl: false }"
  @mousemove="onMapMouseMove"
>
```

关键参数说明：
- **crs="Simple"**：使用简单笛卡尔坐标，y 轴向下为正（与屏幕坐标一致）
- **center="[-128, 128]"**：地图中心点为 [lat, lng] 格式，在 Simple CRS 中即 [y, x]
- **zoom 范围**：0 ~ 6
- **use-global-leaflet="false"**：使用组件内 Leaflet 实例，避免全局污染
- **zoomControl: false**：禁用原生缩放控件，使用自定义控件
- **attributionControl: false**：隐藏版权信息

### 2.3 瓦片图层配置

```html
<l-tile-layer
  :url="tiles"
  no-wrap
  layer-type="base"
  :options="{
    bounds: [
      [0, 0],
      [-256, 256],
    ],
  }"
></l-tile-layer>
```

```js
const tiles = ref("map/tiles/{z}/{x}/{y}.png");
```

参数说明：
- **URL 模板**：`map/tiles/{z}/{x}/{y}.png`，由后端 Go embed 静态服务在 `/map/tiles` 路径下提供
- **no-wrap**：不在水平方向重复平铺
- **bounds**：`[[0, 0], [-256, 256]]`（Leaflet bounds 格式 `[[lat_min, lng_min], [lat_max, lng_max]]`），即瓦片在 Simple CRS 坐标空间中占据 256x256 的区域。注意 lat 范围是 [-256, 0]（y 轴方向），lng 范围是 [0, 256]（x 轴方向）
- **tileSize**：Leaflet Simple CRS 默认为 256 像素
- **zoom 范围**：0~6，与 LMap 的 min/max-zoom 一致

### 2.4 游戏坐标 <-> 地图坐标换算（核心算法）

这是最关键的部分。游戏世界使用虚幻引擎坐标，范围约 -1.4M ~ +1.4M，需要线性映射到 Leaflet Simple CRS 的 [0, 256] x [-256, 0] 坐标空间。

**世界坐标边界常量：**

```js
const LAND_SCAPE = [349400, 724400, -1099400, -724400];
// 索引:       [maxX,    maxY,   minX,      minY]
```

即：
- X 轴范围：-1,099,400 ~ 349,400（跨度 1,448,800）
- Y 轴范围：-724,400 ~ 724,400（跨度 1,448,800）

**世界坐标 -> 地图坐标：**

```js
const toMapPosition = (position) => {
  // hack
  if (position[0] >= -256 && position[0] <= 256) {
    return position;
  }
  const x =
    -256 +
    (256 * (position[0] - LAND_SCAPE[2])) / (LAND_SCAPE[0] - LAND_SCAPE[2]);
  const y =
    (256 * (position[1] - LAND_SCAPE[3])) / (LAND_SCAPE[1] - LAND_SCAPE[3]);
  return [x, y];
};
```

公式展开：

```
x_map = -256 + 256 * (world_x - min_x) / (max_x - min_x)
y_map = 256 * (world_y - min_y) / (max_y - min_y)
```

其中：
- `min_x = -1099400`, `max_x = 349400`
- `min_y = -724400`, `max_y = 724400`

x 映射到 [-256, 0]，y 映射到 [0, 256]。

注意返回值 `[x, y]` 会被 Leaflet 作为 `[lat, lng]` 使用，所以实际 lat=x（负值），lng=y（正值）。这与瓦片 bounds `[[0,0],[-256,256]]` 一致。

"hack" 分支：如果输入坐标已经在 [-256, 256] 范围内，直接透传，兼容已经转换过的坐标。

**地图坐标 -> 世界坐标（逆变换）：**

```js
const fromMapPosition = (mapPosition) => {
  // 还原 x 坐标
  const worldX =
    ((mapPosition[0] + 256) * (LAND_SCAPE[0] - LAND_SCAPE[2])) / 256 +
    LAND_SCAPE[2];
  // 还原 y 坐标
  const worldY =
    (mapPosition[1] * (LAND_SCAPE[1] - LAND_SCAPE[3])) / 256 + LAND_SCAPE[3];

  // 保留两位小数
  return [worldX.toFixed(2), worldY.toFixed(2)];
};
```

**距离换算：**

```js
const toMapDistance = (distance) => {
  return 256 * (distance / (LAND_SCAPE[0] - LAND_SCAPE[2]));
};
```

将游戏世界距离单位映射到地图坐标距离，用于据点范围圆圈的半径。

#### 据点标记

据点支持**聚合显示**（clustering），在低缩放级别下将邻近据点合并：

```js
const clusteredBaseMarkers = computed(() => {
  if (zoom.value >= 5) {
    return rawBaseMarkers.value.map((marker) => ({
      key: marker.key,
      position: marker.position,
      markers: [marker],
    }));
  }

  const cellSize = 48 / 2 ** zoom.value;
  const clusters = new Map();
  rawBaseMarkers.value.forEach((marker) => {
    const clusterKey = `${Math.floor(marker.position[0] / cellSize)}:${Math.floor(
      marker.position[1] / cellSize,
    )}`;
    if (!clusters.has(clusterKey)) clusters.set(clusterKey, []);
    clusters.get(clusterKey).push(marker);
  });

  return Array.from(clusters.entries()).map(([key, markers]) => ({
    key,
    markers,
    position: [
      markers.reduce((sum, marker) => sum + marker.position[0], 0) /
        markers.length,
      markers.reduce((sum, marker) => sum + marker.position[1], 0) /
        markers.length,
    ],
  }));
});
```

聚合算法：
- zoom >= 5 时不聚合，每个据点独立显示
- zoom < 5 时按网格聚合，cellSize = 48 / 2^zoom（地图坐标单位）
- 同一网格内的据点合并为一个标记，位置取平均值
- 聚合标记图标增大到 62x62，显示数量 badge

### 2.8 自动刷新机制

```js
const refreshPlayer = async () => {
  try {
    const { data } = await api.getOnlinePlayerList();
    if (Array.isArray(data.value)) {
      const onlinePlayers = data.value;
      onlinePlayerIds.value = new Set(
        onlinePlayers.map((player) => player.player_uid).filter(Boolean),

```

- 每 **5 秒**轮询 `/api/online_player` 获取在线玩家实时坐标

玩家数据处理工具（`web/src/utils/mapPlayers.js`）：

```js
export const hasMapLocation = (player) => {
  const x = Number(player?.location_x);
  const y = Number(player?.location_y);
  return Number.isFinite(x) && Number.isFinite(y) && (x !== 0 || y !== 0);
};

export const mergeMapPlayers = (players = [], onlinePlayers = []) => {
  const merged = new Map(
    players
      .filter((player) => player?.player_uid)
      .map((player) => [player.player_uid, { ...player }]),
  );
  onlinePlayers.forEach((player) => {
    if (!player?.player_uid) return;
    merged.set(player.player_uid, {
      ...merged.get(player.player_uid),
      ...player,
    });
  });
  return Array.from(merged.values());
};

export const selectVisibleMapPlayers = (
  players = [],
  onlinePlayerIds = new Set(),
  visibility = "online",
) =>
  players.filter(
    (player) =>
      hasMapLocation(player) &&
      (visibility === "all" || onlinePlayerIds.has(player.player_uid)),
  );

export const buildPlayerGuildMap = (guilds = []) => {
  const playerGuilds = new Map();
  guilds.forEach((guild) => {
    (guild?.players || []).forEach((player) => {
      if (player?.player_uid) playerGuilds.set(player.player_uid, guild);
    });
  });
  return playerGuilds;
};
```


未登录时 `ip`、`steam_id` 等敏感字段会被清空，但坐标始终保留。

后端还有定时任务 `PlayerSync`（`internal/task/task.go`）按配置周期调用 `ShowPlayers()` 并写入数据库。

### 3.3 玩家列表 API

**端点**：`GET /api/player`

返回 `[]TersePlayer`，TersePlayer 匿名嵌入 OnlinePlayer，因此也带有 `location_x`/`location_y`：

```go
type TersePlayer struct {
    PlayerUid      string           `json:"player_uid"`
    Nickname       string           `json:"nickname"`
    Level          int32            `json:"level"`
    // ... 其他属性
    OnlinePlayer   // 嵌入，带 location_x/location_y
}
```

坐标更新策略（`service/player.go`）：存档同步时**保留数据库中已有的在线坐标**，不被存档覆盖。坐标永远以 REST API 实时数据为准。

### 3.4 公会据点数据 API

**端点**：`GET /api/guild`

**Handler 文件**：`api/guild.go`，函数 `listGuilds`

数据结构：

```go
type BaseCamp struct {
    Id        string  `json:"id"`
    Area      float64 `json:"area"`
    LocationX float64 `json:"location_x"`
    LocationY float64 `json:"location_y"`
}

type Guild struct {
    Name           string         `json:"name"`
    BaseCampLevel  int32          `json:"base_camp_level"`
    AdminPlayerUid string         `json:"admin_player_uid"`
    Players        []*GuildPlayer `json:"players"`
    BaseCamp       []BaseCamp     `json:"base_camp"`
}
```

据点数据来源：**Level.sav 存档文件解析**，由外部 Python 工具 `sav_cli` 完成。

解析流程：
1. `sav_cli/structurer.py` 的 `structure_base_camp()` 从存档 `BaseCampSaveData` 读取据点
2. 坐标取自 `transform.translation.x` / `transform.translation.y`（虚幻引擎坐标）
3. 面积取自 `area_range` 字段
4. `structure_guild()` 通过 `base_ids` 将据点关联到公会
5. 解析结果通过 PUT `/api/guild` 回传 Go 后端

```python
guild["base_camp"].append({
    "id": camp["id"],
    "area": camp["area_range"],
    "location_x": camp["transform"]["x"],
    "location_y": camp["transform"]["y"],
})
```

定时任务 `SavSync` 按 `Save.SyncInterval` 周期触发存档解析。

### 3.5 帕鲁位置数据

**不支持。** `Pal` 结构体（`internal/database/models.go`）只包含等级、HP、属性、技能等战斗数据，没有任何坐标字段。野生帕鲁位置完全未解析。

### 3.6 静态地图数据

前端静态坐标数据位于 `web/src/assets/map/points.json`（随前端打包，非 public 目录）：
- `boss_tower`：9 个 Boss 塔坐标
- `fast_travel`：137 个快速旅行点坐标

`web/public/` 目录下没有任何地图相关文件（仅有 favicon.ico）。

### 3.7 后端坐标处理

后端**不做任何坐标转换**。它只透传 `location_x`/`location_y` 的原始虚幻引擎坐标值。所有坐标到瓦片像素的映射完全在前端 `toMapPosition()` 中完成。

## 四、瓦片静态资源

### 4.1 瓦片服务方式

瓦片通过 Go `embed.FS` 编译进二进制文件：

```go
//go:embed map/*
var mapTiles embed.FS

mapTilesFS, _ := fs.Sub(mapTiles, "map")
router.StaticFS("/map/tiles", http.FS(mapTilesFS))
```

前端通过相对路径 `map/tiles/{z}/{x}/{y}.png` 访问。

### 4.2 瓦片来源

下载脚本 `map_down.py` 从 palworld.gg 下载：

```python
base_url = "https://palworld.gg/images/tiles/{z}/{x}/{y}.png"
```

### 4.3 瓦片规格

- 尺寸：256x256 像素
- 格式：PNG, 8-bit RGBA, 非交错
- Zoom 0-5 为完整网格
- Zoom 6 仅 1398/4096 个瓦片（空白海洋区域未下载）
- 空白瓦片文件大小约 665 字节（最小有效 PNG）
