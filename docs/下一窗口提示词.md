你正在接手 PalAdmin 项目（幻兽帕鲁服务器管理面板）。开始工作前请按以下步骤：

1. **先读开发规范**：`docs/开发规范.md`，这是最重要的文档，包含当前架构、代码位置、开发约定和已踩过的 13 个坑。
2. **查看当前状态**：
   - 分支：main
   - 最新版本：v3.0.0（Docker 化部署）
   - 最近提交：`git log --oneline -10`
3. **项目架构要点**：
   - 后端 Go 1.22 + Gin + bbolt，前端 Vue 3 + TS + Naive UI + Vite
   - Docker Compose 双容器：paladmin（面板）+ gameserver（SteamCMD+GE-Proton+PalServer+PalDefender）
   - 面板挂载 /var/run/docker.sock 管控游戏服容器
   - 只运行 Windows 版 PalServer（通过 GE-Proton），无 Linux 原生模式
   - 所有 GitHub 下载必须走 `internal/github` 包（国内镜像），不要硬编码直链
4. **必读文档**：
   - `docs/开发规范.md`（架构、约定、踩坑记录）
   - `docs/Docker部署.md`（部署和运维）
   - `docs/Proton部署说明.md`（非 Docker 部署）
5. **开发纪律**：
   - 用后台子代理做多文件重构后，必须立即跑 `go build ./...`、`go vet ./...`、`cd web && npm run build` 验证
   - 新增设置键要在 `api/settings.go` 的 `isEditableKey()` 注册
   - 前端 API 调用统一走 `web/src/api/`
   - 发版只推 Gitee，自动同步 GitHub，保留最近 5 个 tag

待办事项见 `docs/开发规范.md` 第八章"待办/已知问题"。现在请告诉我你要做什么，我会配合。
